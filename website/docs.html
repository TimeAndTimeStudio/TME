Render

TEMF Runtime รองรับทั้ง WebGPU และ WebGL สำหรับ rendering — รันได้กว้างกว่า

rect(x, y, width, height, color, rotation?, scale?, alpha?)

วาดสี่เหลี่ยมพร้อมการแปลงรูปทรง (rotation: องศา, scale: ตัวคูณ, alpha: ความโปร่งใส 0-1)

rect(100, 100, 64, 64, "#FF5733") rect(200, 200, 50, 50, "#33FF57", 45, 2, 0.5)

image(src, x, y, rotation?, scale?, alpha?, cropX?, cropY?, cropEndX?, cropEndY?)

โหลดและวาดภาพ (crop ใช้จุดเริ่ม-จุดจบ)

image("assets/player.png", 100, 100) image("assets/sprite.png", 200, 150, 0, 1.5, 1, 10, 10, 90, 90)

getCanvasSize()

ดึงขนาดปัจจุบันของ canvas (รวม DPR)

function draw(): size = getCanvasSize() W = size.width H = size.height rect(0, H-50, W, 50, "brown")

Render

TEMF Runtime supports both WebGPU and WebGL for rendering — wider compatibility.

rect(x, y, width, height, color, rotation?, scale?, alpha?)

Draw a rectangle with optional transforms (rotation: degrees, scale: multiplier, alpha: opacity 0-1).

rect(100, 100, 64, 64, "#FF5733") rect(200, 200, 50, 50, "#33FF57", 45, 2, 0.5)

image(src, x, y, rotation?, scale?, alpha?, cropX?, cropY?, cropEndX?, cropEndY?)

Load and draw an image (crop uses start-end coordinates).

image("assets/player.png", 100, 100) image("assets/sprite.png", 200, 150, 0, 1.5, 1, 10, 10, 90, 90)

getCanvasSize()

Get current canvas size (including DPR).

Input

รองรับ keyboard, mouse และ touch

Keyboard

ใช้ฟังก์ชัน key(key) ตรวจสอบว่ากดปุ่มอยู่หรือไม่

function update(dt): if key("ArrowLeft"): player.x -= 200 * dt if key("ArrowRight"): player.x += 200 * dt if key(" "): player.jumping = true

Mouse

รองรับเมาส์ 3 ปุ่ม

  • 0 = ปุ่มซ้าย (Left Click)
  • 1 = ปุ่มกลาง (Middle Click / Scroll Wheel)
  • 2 = ปุ่มขวา (Right Click)
function draw(): print(mouse.x, mouse.y) if mouse.down(0): if mouse.x > 100 and mouse.x < 200: if mouse.y > 100 and mouse.y < 150: startGame() if mouse.down(2): print("Right click detected")

Touch

รองรับสูงสุด 4 นิ้ว พร้อมกัน (Multi-Touch)

  • touch.down(0) — นิ้วที่ 0 กดอยู่
  • touch.down(1) — นิ้วที่ 1 กดอยู่
  • touch.down(2) — นิ้วที่ 2 กดอยู่
  • touch.down(3) — นิ้วที่ 3 กดอยู่
function update(dt): if touch.down(0): player.x = touch.x(0) player.y = touch.y(0) if touch.down(1): fireBullet(touch.x(1), touch.y(1))

Input

Supports keyboard, mouse, and touch input.

Keyboard

Use the key(key) function to check if a key is pressed.

function update(dt): if key("ArrowLeft"): player.x -= 200 * dt if key("ArrowRight"): player.x += 200 * dt if key(" "): player.jumping = true

Mouse

Supports 3 mouse buttons.

  • 0 = Left Click
  • 1 = Middle Click / Scroll Wheel
  • 2 = Right Click
function draw(): print(mouse.x, mouse.y) if mouse.down(0): if mouse.x > 100 and mouse.x < 200: if mouse.y > 100 and mouse.y < 150: startGame() if mouse.down(2): print("Right click detected")

Touch

Supports up to 4 simultaneous touches (Multi-Touch).

  • touch.down(0) — Finger 0 is pressed
  • touch.down(1) — Finger 1 is pressed
  • touch.down(2) — Finger 2 is pressed
  • touch.down(3) — Finger 3 is pressed
function update(dt): if touch.down(0): player.x = touch.x(0) player.y = touch.y(0) if touch.down(1): fireBullet(touch.x(1), touch.y(1))

Visibility

ระบบตรวจสอบว่าผู้เล่นเคยสลับออกจาก tab ระหว่างเล่นเกมหรือไม่

hasTabSwitched()

คืนค่า true หากผู้เล่นเคยสลับออกจาก tab (หรือย่อ/สลับแอป) อย่างน้อยหนึ่งครั้งนับตั้งแต่โหลดหน้าเว็บ ค่าจะเป็น true ค้างตลอด ไม่รีเซ็ตกลับเป็น false จนกว่าจะโหลดหน้าเว็บใหม่

function draw(): if hasTabSwitched(): print("ผู้เล่นเคยสลับ tab ไปแล้ว")

Visibility

System for checking whether the player has switched away from the tab during gameplay.

hasTabSwitched()

Returns true if the player has switched away from the tab (or minimized/switched apps) at least once since the page was loaded. The value stays true and does not reset to false until the page is reloaded.

function draw(): if hasTabSwitched(): print("Player has switched tabs")

Preload

ระบบโหลดทรัพยากรล่วงหน้า (รูปภาพ, เสียง BGM, SFX) พร้อมระบบตรวจสอบสถานะ

preload(resources)

โหลดไฟล์ที่กำหนดไว้ล่วงหน้า

preload("img/bg.png") preload([ "img/bg.png", "img/character.png", "music/bgm.mp3", "sfx/click.wav" ]) preload({ images: ["img/bg.png", "img/char.png"], bgm: ["music/menu.mp3"], sfx: ["sfx/jump.wav"] })

checkpreload()

ตรวจสอบว่าโหลดทรัพยากรทั้งหมดเสร็จแล้วหรือยัง (คืนค่า true / false)

preload(["img/bg.png", "music/bgm.mp3"]) while not checkpreload(): rect(0, 0, 800, 600, "#000000") print("Loading...") print("โหลดเสร็จแล้ว!")

preloadfailed()

ตรวจสอบว่ามีไฟล์ไหนโหลดล้มเหลวหรือไม่ (คืนค่า true ถ้ามีล้มเหลว, false ถ้าสำเร็จทั้งหมด)

preload(["img/bg.png", "music/bgm.mp3"]) while not checkpreload(): rect(0, 0, 800, 600, "#000000") if preloadfailed(): print("มีไฟล์โหลดไม่สำเร็จ!") preload(["img/bg.png", "music/bgm.mp3"]) while not checkpreload(): rect(0, 0, 800, 600, "#000000") else: print("โหลดสำเร็จทั้งหมด!")

preloadisloaded(path)

ตรวจสอบว่าไฟล์เฉพาะโหลดเสร็จแล้วหรือยัง (คืนค่า true / false)

preload(["img/bg.png", "music/bgm.mp3", "sfx/click.wav"]) while not checkpreload(): rect(0, 0, 800, 600, "#000000") if preloadisloaded("img/bg.png"): print("Background พร้อมใช้งาน") else: print("Background ยังโหลดไม่เสร็จ") if preloadisloaded("music/bgm.mp3"): audio.play("music/bgm.mp3", "bgm") else: print("BGM ยังโหลดไม่พร้อม")

ตัวอย่างเต็ม: Loading Screen

function init(): preload([ "img/bg.png", "img/character.png", "music/bgm.mp3", "sfx/click.wav", "sfx/explosion.wav" ]) function update(dt): if not checkpreload(): return if preloadfailed(): preload([ "img/bg.png", "img/character.png", "music/bgm.mp3", "sfx/click.wav", "sfx/explosion.wav" ]) return print("Game Ready!") function draw(): if not checkpreload(): rect(0, 0, 800, 600, "#000000") print("Loading...") rect(100, 300, 600, 20, "#333333") rect(100, 300, 600 * progress, 20, "#FF5733") else: rect(0, 0, 800, 600, "#87CEEB") image("img/character.png", 100, 200)

Preload

Preload resources (images, BGM, SFX) with status checking system.

preload(resources)

Load specified resources in advance.

preload("img/bg.png") preload([ "img/bg.png", "img/character.png", "music/bgm.mp3", "sfx/click.wav" ]) preload({ images: ["img/bg.png", "img/char.png"], bgm: ["music/menu.mp3"], sfx: ["sfx/jump.wav"] })

checkpreload()

Check if all resources have finished loading (returns true / false).

preload(["img/bg.png", "music/bgm.mp3"]) while not checkpreload(): rect(0, 0, 800, 600, "#000000") print("Loading...") print("Loading complete!")

preloadfailed()

Check if any files failed to load (returns true if failed, false if all succeeded).

preload(["img/bg.png", "music/bgm.mp3"]) while not checkpreload(): rect(0, 0, 800, 600, "#000000") if preloadfailed(): print("Some files failed to load!") preload(["img/bg.png", "music/bgm.mp3"]) while not checkpreload(): rect(0, 0, 800, 600, "#000000") else: print("All files loaded successfully!")

preloadisloaded(path)

Check if a specific file has finished loading (returns true / false).

preload(["img/bg.png", "music/bgm.mp3", "sfx/click.wav"]) while not checkpreload(): rect(0, 0, 800, 600, "#000000") if preloadisloaded("img/bg.png"): print("Background is ready") else: print("Background not loaded yet") if preloadisloaded("music/bgm.mp3"): audio.play("music/bgm.mp3", "bgm") else: print("BGM not ready yet")

Full Example: Loading Screen

function init(): preload([ "img/bg.png", "img/character.png", "music/bgm.mp3", "sfx/click.wav", "sfx/explosion.wav" ]) function update(dt): if not checkpreload(): return if preloadfailed(): preload([ "img/bg.png", "img/character.png", "music/bgm.mp3", "sfx/click.wav", "sfx/explosion.wav" ]) return print("Game Ready!") function draw(): if not checkpreload(): rect(0, 0, 800, 600, "#000000") print("Loading...") rect(100, 300, 600, 20, "#333333") rect(100, 300, 600 * progress, 20, "#FF5733") else: rect(0, 0, 800, 600, "#87CEEB") image("img/character.png", 100, 200)

ตัวอย่างโค้ด TSL

ตัวอย่างการใช้งาน TSL กับ TEMF Runtime — เกมผู้เล่นเคลื่อนที่ได้

# Variables let playerX = 100 let playerY = 200 let speed = 200 let direction = "right" # Function: Update game state function update(dt): # Handle keyboard input if key("ArrowLeft"): playerX -= speed * dt direction = "left" if key("ArrowRight"): playerX += speed * dt direction = "right" if key("ArrowUp"): playerY -= speed * dt if key("ArrowDown"): playerY += speed * dt # Boundary checking if playerX < 0: playerX = 0 if playerX > 800: playerX = 800 if playerY < 0: playerY = 0 if playerY > 600: playerY = 600 # Function: Render game function draw(): # Clear screen with blue sky rect(0, 0, 800, 600, "#87CEEB") # Draw ground rect(0, 550, 800, 50, "#228B22") # Draw player character if direction == "right": rect(playerX, playerY, 50, 50, "#FF5733") else: rect(playerX, playerY, 50, 50, "#33FF57") # Register game loop setGame({ update: update, draw: draw }) # Set target FPS fps(60)

TSL usage example with TEMF Runtime — Moving player game.
