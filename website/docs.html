เริ่มต้นใช้งาน

TME (Time Mini Engine) คือ game engine ขนาดเล็กสำหรับสร้างเกม 2D ใช้ WebGPU สำหรับ render และมี build system ที่เรียบง่าย

การติดตั้ง

git clone https://github.com/TimeAndTimeStudio/TME.git cd TME

สร้างโปรเจกต์ใหม่

cd examples mkdir my-game cd my-game

Build

cd /path/to/TME node tme/bin/tme build

รันเกม

เปิด index.html ในเบราว์เซอร์

Getting Started

TME (Time Mini Engine) is a small game engine for creating 2D games. Uses WebGPU for rendering and has a simple build system.

Installation

git clone https://github.com/TimeAndTimeStudio/TME.git cd TME

Create New Project

cd examples mkdir my-game cd my-game

Build

cd /path/to/TME node tme/bin/tme build

Run Game

Open index.html in browser

Project Structure

โครงสร้างโปรเจกต์

my-game/ ├── game.tsl # Game source code ├── index.html # HTML page with canvas ├── style.css # User CSS ├── assets/ # User assets (images, audio) └── dist/ # Build output

ไฟล์ที่จำเป็น

  • game.tsl — Game source code
  • index.html — ต้องมี <canvas id="game">
  • style.css — User CSS (optional)

Project Structure

Project Layout

my-game/ ├── game.tsl # Game source code ├── index.html # HTML page with canvas ├── style.css # User CSS ├── assets/ # User assets (images, audio) └── dist/ # Build output

Required Files

  • game.tsl — Game source code
  • index.html — Must contain <canvas id="game">
  • style.css — User CSS (optional)

Render

TME ใช้ WebGPU สำหรับ rendering — ไม่มี Canvas2D/WebGL fallback

rect()

วาดสี่เหลี่ยม

rect(x, y, width, height, color)
ParameterTypeDescription
x, ynumberตำแหน่ง
width, heightnumberขนาด
colorstringสี (hex, rgb, หรือชื่อสี)

image()

วาดรูปภาพ

image(src, x, y, width, height)

Image โหลดแบบ on-demand — โหลดเมื่อใช้เท่านั้น

getCanvasSize()

ดึงขนาดปัจจุบันของ canvas (รวม DPR)

function draw(): size = getCanvasSize() W = size.width H = size.height # ใช้ W, H ในการคำนวณตำแหน่ง rect(0, H-50, W, 50, "brown")

Render

TME uses WebGPU for rendering — no Canvas2D/WebGL fallback.

rect()

Draw a rectangle.

rect(x, y, width, height, color)
ParameterTypeDescription
x, ynumberPosition
width, heightnumberSize
colorstringColor (hex, rgb, or named)

image()

Draw an image.

image(src, x, y, width, height)

Images load on-demand — only loaded when used.

getCanvasSize()

Get current canvas size (including DPR).

function draw(): size = getCanvasSize() W = size.width H = size.height # Use W, H for positioning rect(0, H-50, W, 50, "brown")

Mouse API

Mouse API แบบเต็มรูปแบบ

mouse.x, mouse.y

ตำแหน่งเมาส์

print(f"Mouse at {mouse.x}, {mouse.y}")

mouse.click(btn)

ตรวจสอบ click (btn = 0 สำหรับ left, 1 สำหรับ right)

if mouse.click(0): print("Left mouse clicked")

mouse.down(btn)

ตรวจสอบว่ากดปุ่มเมาส์อยู่หรือไม่

if mouse.down(0): print("Left mouse button down")

mouse.drag(btn)

ตรวจสอบ drag (auto-reset หลังอ่าน)

if mouse.drag(0): print("Mouse dragging")

mouse.up(btn)

ตรวจสอบปล่อยปุ่มเมาส์

if mouse.up(0): print("Left mouse button up")

Mouse API

Full-featured mouse API

mouse.x, mouse.y

Mouse position.

print(f"Mouse at {mouse.x}, {mouse.y}")

mouse.click(btn)

Check click (btn = 0 for left, 1 for right).

if mouse.click(0): print("Left mouse clicked")

mouse.down(btn)

Check if mouse button is pressed.

if mouse.down(0): print("Left mouse button down")

mouse.drag(btn)

Check drag (auto-reset after read).

if mouse.drag(0): print("Mouse dragging")

mouse.up(btn)

Check mouse button release.

if mouse.up(0): print("Left mouse button up")

Audio

ใช้ audio object เดียวสำหรับ SFX และ BGM

audio.play()

เล่นเสียง SFX หรือ BGM

audio.play("sfx_jump", "sfx") audio.play("bgm_main", "bgm", true)

audio.stop()

หยุดเสียง SFX, BGM, หรือทั้งหมด

audio.stop("sfx") # หยุด SFX ทั้งหมด audio.stop("bgm") # หยุด BGM audio.stop() # หยุดทั้งหมด

audio.pause(), audio.resume()

หยุดชั่วคราว และ เล่นต่อ

audio.pause() audio.resume()

audio.volume, audio.sfxVolume, audio.bgmVolume

ปรับระดับเสียง (0.0 - 1.0)

audio.volume = 0.5 audio.sfxVolume = 0.8 audio.bgmVolume = 0.6

audio.muted, audio.mutedSfx, audio.mutedBgm

ปิดเสียง

audio.muted = true audio.mutedSfx = true audio.mutedBgm = true

Audio

Uses one unified audio object for SFX and BGM.

audio.play()

Play SFX or BGM.

audio.play("sfx_jump", "sfx") audio.play("bgm_main", "bgm", true)

audio.stop()

Stop SFX, BGM, or all.

audio.stop("sfx") # Stop all SFX audio.stop("bgm") # Stop BGM audio.stop() # Stop all

audio.pause(), audio.resume()

Pause and resume BGM.

audio.pause() audio.resume()

audio.volume, audio.sfxVolume, audio.bgmVolume

Adjust volume (0.0 - 1.0).

audio.volume = 0.5 audio.sfxVolume = 0.8 audio.bgmVolume = 0.6

audio.muted, audio.mutedSfx, audio.mutedBgm

Mute audio.

audio.muted = true audio.mutedSfx = true audio.mutedBgm = true

Fullscreen API

ระบบจัดการโหมดเต็มหน้าจอและ callback เมื่อออกจาก fullscreen

requestFullscreen()

เข้าสู่โหมดเต็มหน้าจอ

# กดปุ่ม F11 if input.keyboard.is_down("f11"): requestFullscreen()

exitFullscreen()

ออกจากโหมดเต็มหน้าจอ

# กด ESC (browser ทำให้อัตโนมัติ) # หรือกดปุ่มบนจอ if input.keyboard.is_down("escape"): exitFullscreen()

setFullscreenCallback()

ลงทะเบียนฟังก์ชันเมื่อออกจาก fullscreen

function onFullscreenExit(): print("ออกจาก fullscreen!") # ทำอย่างอื่น เช่น pause game setFullscreenCallback(onFullscreenExit)

Fullscreen API

Fullscreen mode management and exit callback system.

requestFullscreen()

Enter fullscreen mode.

# Press F11 if input.keyboard.is_down("f11"): requestFullscreen()

exitFullscreen()

Exit fullscreen mode.

# Press ESC (browser does automatically) # Or press button on screen if input.keyboard.is_down("escape"): exitFullscreen()

setFullscreenCallback()

Register a function when exiting fullscreen.

function onFullscreenExit(): print("Exited fullscreen!") # Do something: pause game, show menu, etc. setFullscreenCallback(onFullscreenExit)

Build

Build Program orchestrate การ build ทั้งหมด

คำสั่ง

cd /path/to/TME node tme/bin/tme build

Output

dist/ ├── index.html ├── game.js ├── engine.js ├── style.css └── assets/

กฎสำคัญ

  • WebGPU เท่านั้น — ไม่มี fallback
  • index.html ต้องมี canvas#game
  • style.css เป็น user-owned — build ไม่ทับ
  • TSL เป็น external read-only — build ไม่แก้

Build

Build Program orchestrates the entire build process.

Commands

cd /path/to/TME node tme/bin/tme build

Output

dist/ ├── index.html ├── game.js ├── engine.js ├── style.css └── assets/

Important Rules

  • WebGPU only — no fallback
  • index.html must have canvas#game
  • style.css is user-owned — build never overwrites
  • TSL is external read-only — build never modifies
