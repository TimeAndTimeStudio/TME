เริ่มต้นใช้งาน

TME (Time Mini Engine) คือ game engine ขนาดเล็กสำหรับสร้างเกม 2D ใช้ WebGPU สำหรับ render และมี build system ที่เรียบง่าย

การติดตั้ง

git clone https://github.com/TimeAndTimeStudio/TME.git cd TME

สร้างโปรเจกต์ใหม่

cd examples mkdir my-game cd my-game

Build

cd /path/to/TME node tme/bin/tme build

รันเกม

เปิด index.html ในเบราว์เซอร์

Getting Started

TME (Time Mini Engine) is a small game engine for creating 2D games. Uses WebGPU for rendering and has a simple build system.

Installation

git clone https://github.com/TimeAndTimeStudio/TME.git cd TME

Create New Project

cd examples mkdir my-game cd my-game

Build

cd /path/to/TME node tme/bin/tme build

Run Game

Open index.html in browser

Project Structure

โครงสร้างโปรเจกต์

my-game/ ├── game.tsl # Game source code ├── index.html # HTML page with canvas ├── style.css # User CSS ├── assets/ # User assets (images, audio) └── dist/ # Build output

ไฟล์ที่จำเป็น

  • game.tsl — Game source code
  • index.html — ต้องมี <canvas id="game">
  • style.css — User CSS (optional)

Render

TME ใช้ WebGPU สำหรับ rendering — ไม่มี Canvas2D/WebGL fallback

rect(x, y, width, height, color, rotation?, scale?, alpha?)

วาดสี่เหลี่ยมพร้อมการแปลงรูปทรง

rect(100, 100, 64, 64, "#FF5733") rect(200, 200, 50, 50, "#33FF57", 45, 2, 0.5)

image(src, x, y, width?, height?, rotation?, scale?, alpha?)

โหลดและวาดภาพ

image("assets/player.png", 100, 100, 64, 64) image("assets/sprite.png", 200, 150, 90, 1.5, 0.8)

getCanvasSize()

ดึงขนาดปัจจุบันของ canvas (รวม DPR)

function draw(): size = getCanvasSize() W = size.width H = size.height # ใช้ W, H ในการคำนวณตำแหน่ง rect(0, H-50, W, 50, "brown")

Render

TME uses WebGPU for rendering — no Canvas2D/WebGL fallback.

rect(x, y, width, height, color, rotation?, scale?, alpha?)

Draw a rectangle with optional transforms.

rect(100, 100, 64, 64, "#FF5733") rect(200, 200, 50, 50, "#33FF57", 45, 2, 0.5)

image(src, x, y, width?, height?, rotation?, scale?, alpha?)

Load and draw an image.

image("assets/player.png", 100, 100, 64, 64) image("assets/sprite.png", 200, 150, 90, 1.5, 0.8)

getCanvasSize()

Get current canvas size (including DPR).

function draw(): size = getCanvasSize() W = size.width H = size.height # Use W, H for positioning rect(0, H-50, W, 50, "brown")

Input

รองรับ keyboard, mouse และ touch

Keyboard

ใช้ฟังก์ชัน key(key) ตรวจสอบว่ากดปุ่มอยู่หรือไม่

function update(dt): if key("ArrowLeft"): player.x -= 200 * dt if key("ArrowRight"): player.x += 200 * dt if key(" "): player.jumping = true

Mouse

รองรับเมาส์ 3 ปุ่ม

  • 0 = ปุ่มซ้าย (Left Click)
  • 1 = ปุ่มกลาง (Middle Click / Scroll Wheel)
  • 2 = ปุ่มขวา (Right Click)
function draw(): print(mouse.x, mouse.y) if mouse.down(0): # ปุ่มซ้าย if mouse.x > 100 and mouse.x < 200: if mouse.y > 100 and mouse.y < 150: startGame() if mouse.down(2): # ปุ่มขวา print("Right click detected")

Touch

รองรับสูงสุด 4 นิ้ว พร้อมกัน (Multi-Touch)

  • touch.down(0) — นิ้วที่ 0 กดอยู่
  • touch.down(1) — นิ้วที่ 1 กดอยู่
  • touch.down(2) — นิ้วที่ 2 กดอยู่
  • touch.down(3) — นิ้วที่ 3 กดอยู่
function update(dt): if touch.down(0): # นิ้วแรก player.x = touch.x(0) player.y = touch.y(0) if touch.down(1): # นิ้วสอง (Multi-Touch) fireBullet(touch.x(1), touch.y(1))

Build

Build Program orchestrate การ build ทั้งหมด

คำสั่ง

cd /path/to/TME node tme/bin/tme build

Output

my-game/ ├── index.html ├── game.js ├── temf.js ├── temf-webgpu.js ├── temf-webgl.js ├── style.css └── assets/ (หรือชื่ออื่น)

กฎสำคัญ

  • WebGPU เท่านั้น — ไม่มี fallback
  • index.html ต้องมี canvas#game
  • style.css เป็น user-owned — build ไม่ทับ

Build

Build Program orchestrates the entire build process.

Commands

cd /path/to/TME node tme/bin/tme build

Output

my-game/ ├── index.html ├── game.js ├── temf.js ├── temf-webgpu.js ├── temf-webgl.js ├── style.css └── assets/ (or any name)

Important Rules

  • WebGPU only — no fallback
  • index.html must have canvas#game
  • style.css is user-owned — build never overwrites
