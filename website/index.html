คุณสมบัติ Features

Simple Syntax

ใช้ colon (:) และ indentation กำหนด block ไม่มี curly braces หรือ end keyword Uses colon (:) and indentation for blocks — no curly braces or end keywords needed

WebGPU Rendering

ใช้ WebGPU สำหรับ render ทั้งหมด — rect(), image() — รันเร็วและทันสมัย WebGPU for all rendering — rect(), image() — fast and modern graphics

Fast Build

tme build — compile game.tsl ผ่าน TSL compiler สร้าง static dist/ ทันที tme build — compile game.tsl via TSL compiler, output static dist/ instantly

Input System

รองรับ keyboard, mouse, touch — ควบคุมเกมได้ง่าย Keyboard, mouse, touch support — easy game control

Game Loop

Fixed timestep update — start() แล้วเริ่ม loop ทันที ไม่ซับซ้อน Fixed timestep update — call start() and loop runs automatically

Static Export

Export เป็น static HTML/JS/CSS — วางบน server ใดก็ได้ รันได้เลย Export as static HTML/JS/CSS — deploy anywhere, runs immediately
