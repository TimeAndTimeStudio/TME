TSL (Time Script Language) — Write easy, read easy, transpile to JavaScript

เริ่มต้นใช้งาน Get Started เรียนรู้เพิ่มเติม Learn More
# Fibonacci
function fib(n):
    if n <= 1:
        return n
    return fib(n - 1) + fib(n - 2)

for i in range(10):
    print(fib(i))

แปลงเป็น: Compiles to:

function fib(n) {
  if (n <= 1) {
    return n;
  }
  return fib(n - 1) + fib(n - 2);
}

for (let i of range(10)) {
  console.log(fib(i));
}

คุณสมบัติ Features

Simple Syntax

ใช้ colon (:) และ indentation กำหนด block ไม่มี curly braces หรือ end keyword Uses colon (:) and indentation for blocks — no curly braces or end keywords needed

Full Compiler Pipeline

Lexer → Parser → AST → Validator → Generator — แปลงเป็น JavaScript ที่สะอาดและอ่านได้ Lexer → Parser → AST → Validator → Generator — compiles to clean, readable JavaScript

Deterministic Output

Source เดิมให้ output เดียวกันทุกครั้ง predictable และเข้าใจง่าย Same source always produces the same JavaScript — predictable and easy to understand

Rich Type Support

รองรับ numbers, strings, booleans, null, arrays, objects Supports numbers, strings, booleans, null, arrays, objects

Control Flow

if/else, for, while, break, continue — ควบคุมการทำงานได้ครบ if/else, for, while, break, continue — full control flow support

CLI Tool

build, check, run จาก command line รองรับ compile เป็นไฟล์ .js build, check, run from command line — compile to .js files
