เริ่มต้นใช้งาน

TSL (Time Script Language) คือภาษาโปรแกรมขนาดเล็กที่ transpile เป็น JavaScript ใช้ indentation สำหรับ block และมี syntax ที่เรียบง่าย

การติดตั้ง

git clone https://github.com/TimeAndTimeStudio/TSL.git cd TSL

Quick Start

สร้างไฟล์ hello.tsl:

# Hello World
print("Hello, World!")

Compile:

node src/cli.js hello.tsl

Build เป็น JavaScript

node src/cli.js build hello.tsl -o hello.js

รัน JavaScript ที่สร้าง

node hello.js

Getting Started

TSL (Time Script Language) is a small programming language that transpiles to JavaScript. It uses indentation for blocks and has simple syntax.

Installation

git clone https://github.com/TimeAndTimeStudio/TSL.git cd TSL

Quick Start

Create a file hello.tsl:

# Hello World
print("Hello, World!")

Compile:

node src/cli.js hello.tsl

Build to JavaScript

node src/cli.js build hello.tsl -o hello.js

Run the Generated JavaScript

node hello.js

Variables

Assignment ใช้ = การ assign ครั้งแรกใน scope จะสร้างตัวแปร (generate let)

x = 10 # generates: let x = 10;
x = 20 # generates: x = 20;

Identifiers

  • Must start with a letter or _
  • Followed by letters, digits, or _
  • Case-sensitive
  • Cannot be a keyword

Variables

Assignment uses =. The first assignment in a scope creates a variable (generates let).

x = 10 # generates: let x = 10;
x = 20 # generates: x = 20;

Identifiers

  • Must start with a letter or _
  • Followed by letters, digits, or _
  • Case-sensitive
  • Cannot be a keyword

Control Flow

If / Else

x = 15
if x > 10:
    print("big")
else:
    print("small")

While

counter = 3
while counter > 0:
    print(counter)
    counter = counter - 1

For

for i in range(5):
    print(i)

Break / Continue

for i in range(10):
    if i == 3:
        continue
    if i == 7:
        break
    print(i)
